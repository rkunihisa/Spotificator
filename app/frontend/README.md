
# Spotificator Frontend

This is the frontend project for Spotificator, built with Vue 3 and Vite.

## Project Setup

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## About

Spotificator lets you monitor your Spotify insights, create images, and share your listening time and top songs.
